​# Sistema de Gestión de Inventario y Bodegas
​Descripción: Proyecto enfocado en el control, registro y trazabilidad de productos para optimizar la gestión de stock y operaciones en bodega.
​Funcionalidades Clave:
​Registro y categorización de productos/repuestos.
​Control de entradas, salidas y alertas de stock mínimo.
​Estructura pensada para la integración con canales de venta y reportabilidad de inventario.
